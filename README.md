One original line of plain text: a pickup line a vending machine would use on a passing human — an entry for make.fun's [One Line, One Minute: The Vending Machine Pickup Line Contest](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee) bounty ($2, top 10 share the pool). A judge model ranks the lines pairwise on machine voice, machine-world detail, and funniness.

## The line

> I've been humming in this hallway for years, but my coil only spins for you — press B4 and I'll drop my sweetest snack.

119 characters, one line. The machine speaks in the first person, in its own world — humming in the hallway, its coil, slot B4, its snacks — and the punch lands on the last words, warm and cheeky rather than creepy.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (`/output/entry.txt` by default), where the gate reads it. It refuses to write a line outside 1–200 characters or spanning more than one line.
